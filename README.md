# Mr. Bradley Assignments

This is a GitHub respository that stores all the solutions to the assignments Mr. Bradley gave me.

The solutions can be found in both Java, and C++. For each language look inside its allotted folder.

In each folder there will be a ```README.md```. Please follow the instructions in that for compilation, and usage.

The ```examples/``` folder includes my teacher's Java implementation of each assignment.

## Building

Each assignment will follow this organization: ```language/assignmentName/```.

### Java

The Java projects use Gradle, and Groovy to compile, and organize itself. Please ensure you have Gradle, as well as JDK installed on your system.

To ensure that JDK (Java Development Kit) was installed onto your system correctly, please use:

```powershell
java -version
```

### C++

The C+ projects use CMake to compile, and organize its code. Please ensure you have a C++ compiler installed on your machine as well. Natively it uses MSVC to compile. 

To check CMake was installed correctly please use the following command:

```powershell
cmake --version
```
